# UI 현황 전달서

> 앱: `kizami-table/web` · Mock 프로토타입  
> 역할: **조사원(모바일 시연 UI) + 관리자(웹)**

## 한 줄

현장에서 수집한 필지 데이터를 검수하고, 토지이용 변화·탄소 배출량·EUDR 증빙·공급망 이력으로 연결하는 **현장→규제** 엔드투엔드 시연 UI입니다.

## 레이아웃

공통적으로 본문 상단에 **시연 브레드크럼 + 다음 버튼**이 있습니다.

* **관리자**: 좌측 고정 사이드바 + 상단 헤더 + 본문
* **조사원**: 다크 배경 위 모바일 시연 프레임(헤더·본문·하단 버튼)

```text
[관리자]                              [조사원 현장]
┌──────────┬─────────────────┐       ┌──────────────────┐
│ 사이드바  │ 헤더            │       │ 관리자 콘솔 링크   │
│ 시연 1–9 │ 시연 브레드크럼  │       │ ┌──────────────┐ │
│ 마스터   │ 본문            │       │ │ 모바일 프레임  │ │
└──────────┴─────────────────┘       │ │ 본문+하단 버튼 │ │
                                     │ └──────────────┘ │
                                     └──────────────────┘
```

사이드바 **시연 · 현장→규제** 순서와 브레드크럼 순서는 동일합니다.
