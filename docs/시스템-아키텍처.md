# 시스템 아키텍처

```text
[조사원 Mobile ★]          [관리자 Web ★]
 배정 · GPS 폴리곤           검수·승인
 단계 조사서 · 사진          탄소 · DDS/EUDR
 오프라인 캐시(UI)           공급망 · 마스터
      │                           │
      └────────────┬──────────────┘
                   ▼
            KIJANIFY API (mock)
                   │
     ┌─────────────┼──────────────┬──────────┐
     ▼             ▼              ▼          ▼
  생산자/조합   재배지·GPS폴리곤  조사·검증  탄소·DDS
                   │
                   ▼
            공급망 통합 · EUDR geolocation
```

시제품: 조사원 UI는 폰 프레임, GPS 맵은 SVG Mock. 실위성·오프라인 SDK는 후속.

## 모듈 (FP 어플리케이션)

1. 생산자 관리  
2. 재배지 관리 (GPS·폴리곤)  
3. 협동조합 관리  
4. 조사 관리 (현장 입력·상태·승인·검수)  
5. 탄소 관리 (산정·배출계수)  
6. DDS/EUDR 관리  
7. 공급망 관리  
8. 운영 대시보드  
9. 사용자·공지 (시연 최소)

## 외부 연계 (후속)

* 위성/삼림 검증 데이터  
* 오프라인 맵 · 동기화 서버  
* 바이어·수출 포털  
* EUDR DDS 제출 채널
