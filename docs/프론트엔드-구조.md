# 프론트엔드 구조

> 대상: `kizami-table/web`  
> 스택: Next.js 15 · React 19 · TypeScript · Tailwind CSS 4

## 디렉터리

```text
web/
├── public/evidence/          # AI 생성 위성·정사·현장 이미지
│   ├── farm-001/
│   ├── farm-003/
│   └── field/
└── src/
    ├── app/                  # App Router 페이지
    │   ├── page.tsx          # 현황
    │   ├── field/            # 조사원
    │   │   ├── gps/
    │   │   └── survey/[id]/
    │   ├── surveys/
    │   ├── land-use/
    │   ├── carbon|eudr|supply-chain/
    │   ├── producers/
    │   └── farms/[id]/
    ├── components/
    └── data/mock.ts          # 시연 Mock (필지·LUC·핫스팟·로트)
```

## 핵심 컴포넌트

| 컴포넌트 | 역할 |
|----------|------|
| `AppShell` / `Sidebar` | 관리자 레이아웃 · 시연 1–9 + 마스터 네비 |
| `DemoFlowNav` | 시연 브레드크럼 · 「다음」 이동 |
| `FieldShell` | 조사원 모바일 시연 프레임 · 헤더/푸터 |
| `GpsMap` | 정사/위성 위 폴리곤·꼭짓점·삼림 버퍼 |
| `SatelliteTimeline` | 연도별 위성 썸네일 |
| `DegradationOverlay` | 산림전용(D)·황폐화(G) 핫스팟 · 2021 vs 2025 비교 |

## 역할별 UI 진입

| 역할 | 진입 | 셸 |
|------|------|-----|
| 관리자 | `/` 및 웹 경로 | `AppShell` |
| 조사원 | `/field` … | `FieldShell` (폰 프레임) |

관리자 화면에서도 시연 흐름상 `/field` 계열로 이동할 수 있습니다.

## Mock 데이터 포인트

`src/data/mock.ts`에 다음이 함께 정의되어 화면 간 동일 필지·로트를 공유합니다.

* 생산자·재배지·조사·검수 항목
* GPS 웨이포인트·불규칙 폴리곤
* 5년 토지피복·LUC·이미지 좌표 핫스팟
* 탄소 결과(운영 / LUC 분리)·DDS·공급망 단계
