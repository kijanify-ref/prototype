## 1. 한 줄 결론

커피·코코아 공급망의 **생산자·재배지(GPS)·현장조사·탄소·DDS/EUDR** 데이터를 통합하여  
수작업 EUDR 대응을 **플랫폼 기반 추적·산정·문서화**로 전환하는 MVP.

---

## 2. As-is / To-be (사업계획서 요약)

| 구분 | As-is | To-be |
|------|-------|-------|
| 탄소 산정 | 수작업·기준 미비 | 단계별 활동데이터·배출계수 자동 산정 |
| DDS | 담당자 수작업 작성 | 조사·공급망 연계 자동 생성 |
| 조사 | 비정형·메신저 요청 | 단계형 신청·상태·승인 |
| 검증 | 완료 후 수동 검수 | 필수값·GPS 검증·승인 |
| 공급망 | 단계 데이터 분절 | 생산자–농장–가공–운송 연결 |
| EUDR | 증빙 체계 미흡 | GPS·이력·DDS 대응 |

## 3. MVP 범위 (시제품 UI)

| 포함 | 비고 |
|------|------|
| 조사원 모바일 | 배정·GPS 폴리곤·단계 조사서·오프라인 UI |
| GPS·지도 | SVG 맵 · 정확도·폐합·면적 편차 · 재배지 상세 |
