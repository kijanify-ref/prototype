# KIJANIFY — 농업 공급망·탄소·EUDR 통합관리 시제품

**KIJANIFY는 농업 현장에서 수집한 GPS·사진·재배정보를 공급망 이력, 토지이용 변화, 탄소 배출량 및 EUDR 증빙으로 연결하는 통합 관리 플랫폼입니다.**

중소기업 스마트서비스 지원사업을 위해 주식회사 키자미테이블·티벨이 제작한 시제품으로, 현장 조사원과 관리자 업무를 하나의 흐름으로 시연합니다.

**GitHub Pages:** https://kijanify-ref.github.io/prototype/

> 최초 1회: [Settings → Pages](https://github.com/kijanify-ref/prototype/settings/pages)  
> Source = **Deploy from a branch** → Branch = **`gh-pages` / `/ (root)`** → Save  
> (`main` push 시 Actions가 `gh-pages`를 갱신합니다.)

## 핵심 가치

* **현장 데이터 신뢰성 확보** — GPS·사진·조사값을 수집 단계에서 자동 점검
* **탄소·EUDR 데이터 연계** — 동일 필지 데이터를 토지이용 분석과 규제 증빙에 공동 활용
* **업무 전 과정 통합** — 조사 배정부터 검수·탄소 산정·DDS·공급망 추적까지 연결

## 서비스 흐름

```text
현황
→ 현장 조사
→ GPS 수집
→ 조사서 작성
→ 관리자 검수
→ 토지이용 분석
→ 탄소 산정
→ EUDR·DDS
→ 공급망 추적
```

현장 데이터 한 건이 토지이용·탄소·규제 증빙·공급망으로 이어집니다.

## 주요 기능

### 조사원

* 배정 조사 목록 · 오프라인 캐시 · 현장 증빙 이미지
* GPS 필지 경계 — AI 생성 드론 정사영상 위 **불규칙 폴리곤** 수집 · 정확도·면적·폐합 확인
* **단계별** 현장 조사서 (도착 → 경계 → 관행 → 사진 → 제출)
* 필수값·GPS·사진 자동 검증 피드백

### 관리자

* 운영 현황 KPI · 알림
* 조사 검수·승인/반려 (필수값·GPS·면적·사진)
* 재배지 지도 · 불규칙 폴리곤 · 위성 시계열
* **토지이용·5년** — 위성 비교, 산림전용·황폐화 핫스팟, 토지이용변화(LUC) CO₂e
* **탄소 배출량** — 운영 배출과 토지이용변화 배출을 구분하여 표시 · 배출계수
* DDS 보고서 · EUDR 체크리스트 (컷오프 2020-12-31 기준 시연)
* 공급망 단계 추적 · 생산자·협동조합 마스터

## 핵심 시연 화면

| 화면 | 보는 포인트 |
|------|-------------|
| GPS 필지 | 실제 소농처럼 들쭉날쭉한 경계 수집 · 면적·폐합 |
| 토지이용·5년 | EUDR 저위험 사례 vs 황폐화 위험 사례 · 위성 핫스팟 |
| 탄소 | 운영 배출과 LUC를 합산한 로트별 탄소 결과 |
| EUDR·DDS | 컷오프 이후 위성 비교 · 체크리스트 · DDS 준비 상태 |

시연 로트: `LOT-2026-041`(저위험) · `LOT-2026-018`(황폐화 위험)

| 분야 | 기술 |
|------|------|
| Frontend | Next.js 15, React 19, TypeScript |
| UI | Tailwind CSS 4 · 관리자 웹 / 조사원 모바일 시연 UI |
| 지도·증빙 | 폴리곤 오버레이 + AI 생성 위성·정사·현장 이미지 |
| Data | JSON Mock · 5년 토지피복·LUC 시연 데이터 |
| Deploy | GitHub Pages (static export · `basePath=/prototype`) |

## 실행 방법

* Node.js 20+ · 별도 환경변수·외부 API 없음 · 샘플 데이터 기반

```bash
cd web
npm install
npm run dev
```

```text
http://localhost:3000
```

GitHub Pages용 정적 빌드:

```bash
cd web
npm run build:pages
```

## 시제품 범위 및 유의사항

> 제안 및 기능 시연용 프로토타입입니다. 실제 EUDR 신고·수출 증빙·탄소 인증에 사용할 수 없습니다.  
> 지도·GPS·위성 분석·탄소 수치는 샘플 데이터이며, 법규 준수 여부를 확정하지 않습니다.  
> EUDR 시연에서는 컷오프(2020-12-31) 이후 산림감소 여부를 **핵심 위험지표**로 보고, 위성 비교·조사 증빙·체크리스트를 종합해 **시연용 위험 상태**를 표시합니다.
